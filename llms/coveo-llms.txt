# Coveo Docs

> Coveo Docs provides technical documentation, tutorials, and integration guides
> for implementing and optimizing Coveo's AI-powered search and recommendation platform.
>
> For the complete flat page index, see:
> https://docs.coveo.com/en/llms-full.txt

## Platform

- [Home](https://docs.coveo.com/en/llms/sections/root.txt): Overview of the Coveo platform, core capabilities, and getting-started guidance.
- [Manage an Organization](https://docs.coveo.com/en/llms/sections/manage-an-organization.txt): Coveo Administration Console, organization settings, members, groups, and API keys.
- [Security](https://docs.coveo.com/en/llms/sections/security.txt): Data security, compliance standards, and the Coveo Information Security Program.
- [Compliance](https://docs.coveo.com/en/llms/sections/compliance.txt): GDPR, CCPA, HIPAA, and other regulatory compliance features and governance practices.
- [Product Entitlements](https://docs.coveo.com/en/llms/sections/product-entitlements.txt): Entitlements and limitations for Coveo subscriptions.
- [Coveo services](https://docs.coveo.com/en/llms/sections/coveo-services.txt): Coveo Care, Customer Support, Professional Services, and Training Services.
- [Deprecations](https://docs.coveo.com/en/llms/sections/deprecations.txt): Deprecated features, end-of-life timelines, and migration paths.

## Implement Coveo

- [Implementation Guide](https://docs.coveo.com/en/llms/sections/project-guide.txt): Step-by-step implementation guide for deploying Coveo from planning through launch.
- [Index Content](https://docs.coveo.com/en/llms/sections/index-content.txt): Connectors, sources, fields, mappings, and permissions for indexing content from diverse repositories.
- [Build a Search UI](https://docs.coveo.com/en/llms/sections/build-a-search-ui.txt): Atomic, Headless, and REST API approaches for building search interfaces, including component references and code samples.
- [Tune Relevance](https://docs.coveo.com/en/llms/sections/tune-relevance.txt): Query pipelines and their components for fine-tuning search relevance.
- [Monitor and Measure Your Data](https://docs.coveo.com/en/llms/sections/coveo-analytics.txt): Usage analytics for tracking user interactions across search, content, and commerce experiences.
- [Leverage Machine Learning](https://docs.coveo.com/en/llms/sections/leverage-machine-learning.txt): Coveo ML models for generative answering, automatic relevance tuning, and content recommendations.
- [Coveo Customer Service](https://docs.coveo.com/en/llms/sections/service.txt): Case Assist, Insight Panels, and strategies for managing customer service solutions.
- [Knowledge Hub](https://docs.coveo.com/en/llms/sections/knowledge-hub.txt): Centralized platform for insights into content usage in Coveo implementations.
